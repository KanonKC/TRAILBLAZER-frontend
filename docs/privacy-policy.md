# นโยบายความเป็นส่วนตัว (Privacy Policy)

**วันที่มีผลบังคับใช้:** 27 เมษายน 2568

แอปพลิเคชัน **TRAILBLAZER** ("เรา" "แพลตฟอร์ม") ให้ความสำคัญและเคารพต่อความเป็นส่วนตัวของผู้ใช้งาน ("คุณ") นโยบายความเป็นส่วนตัวฉบับนี้จัดทำขึ้นเพื่อให้สอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) เพื่ออธิบายให้คุณทราบถึงวิธีการที่เราเก็บรวบรวม ใช้ เปิดเผย และรักษาข้อมูลส่วนบุคคลของคุณ รวมถึงสิทธิต่างๆ ที่คุณมีในฐานะเจ้าของข้อมูล

---

## 1. ข้อมูลส่วนบุคคลที่เราเก็บรวบรวม

เราเก็บรวบรวมข้อมูลส่วนบุคคลของคุณเท่าที่จำเป็นต่อการให้บริการ โดยแบ่งออกเป็นประเภทต่างๆ ดังนี้:

- **ข้อมูลบัญชีผู้ใช้หลัก (Twitch):** รหัสผู้ใช้ (Twitch ID), ชื่อผู้ใช้งาน (Username), ชื่อที่แสดง (Display Name), และรูปภาพโปรไฟล์ (Avatar URL)
- **ข้อมูลบัญชีที่เชื่อมต่อ (Linked Accounts):** หากคุณเชื่อมต่อบัญชีอื่นๆ เช่น YouTube หรือ Discord เราจะเก็บรหัสผู้ใช้แพลตฟอร์ม (Platform User ID), ชื่อผู้ใช้ (Platform Username), และรูปภาพโปรไฟล์ (Platform Avatar URL)
- **ข้อมูลการให้สิทธิ์เข้าถึง (Authentication Data):** โทเค็นสำหรับการเข้าถึง (Access Tokens) และโทเค็นสำหรับต่ออายุการเข้าถึง (Refresh Tokens) สำหรับ Twitch และบัญชีที่คุณเชื่อมต่อ
- **ข้อมูลการใช้งานแอปพลิเคชันและการตั้งค่า:** ข้อมูลการตั้งค่าวิดเจ็ต (เช่น First Word, Clip Shoutout, Drop Image, Export Video, Random DBD Perk), ข้อมูลไฟล์มีเดียที่คุณอัปโหลด และข้อมูล Workflow และ Trigger ที่คุณปรับแต่ง
- **ข้อมูลที่เก็บรวบรวมอัตโนมัติ:** ข้อมูลทางเทคนิค เช่น หมายเลข IP Address, ชนิดของเบราว์เซอร์, และข้อมูลคุกกี้ (Cookies) เพื่อใช้ในการจัดการเซสชัน (Session)

## 2. ฐานทางกฎหมายในการประมวลผลข้อมูล (Legal Basis)

เราประมวลผลข้อมูลส่วนบุคคลของคุณโดยอาศัยฐานทางกฎหมายดังต่อไปนี้:

| ประเภทข้อมูล | ฐานทางกฎหมาย | คำอธิบาย |
|---|---|---|
| ข้อมูลบัญชี Twitch และบัญชีที่เชื่อมต่อ | **สัญญา (Contract)** | จำเป็นเพื่อให้บริการตามที่คุณร้องขอ |
| Access Tokens / Refresh Tokens | **สัญญา (Contract)** | จำเป็นต่อการทำงานของระบบและวิดเจ็ต |
| ข้อมูลการตั้งค่าและ Workflow | **สัญญา (Contract)** | จำเป็นเพื่อให้ฟีเจอร์ทำงานตามที่คุณปรับแต่ง |
| ข้อมูล IP, Cookies, Session | **ประโยชน์โดยชอบธรรม (Legitimate Interest)** | เพื่อความปลอดภัยและการจัดการระบบ |
| การวิเคราะห์เพื่อปรับปรุงแอปพลิเคชัน | **ประโยชน์โดยชอบธรรม (Legitimate Interest)** | เพื่อพัฒนาคุณภาพการให้บริการ |

## 3. วัตถุประสงค์ในการเก็บรวบรวมและการใช้ข้อมูล

เรานำข้อมูลส่วนบุคคลของคุณไปใช้เพื่อวัตถุประสงค์ดังต่อไปนี้:

- **เพื่อให้บริการและจัดการบัญชี:** เพื่อยืนยันตัวตน เข้าสู่ระบบ และอำนวยความสะดวกในการใช้งานแอปพลิเคชัน TRAILBLAZER
- **เพื่อการทำงานของระบบและวิดเจ็ต:** เพื่อให้วิดเจ็ต ฟีเจอร์ และบอทต่างๆ ทำงานร่วมกับช่อง Twitch ของคุณและแพลตฟอร์มอื่นๆ ได้อย่างถูกต้อง
- **เพื่อการปรับปรุงแอปพลิเคชัน:** เพื่อนำข้อมูลไปวิเคราะห์และพัฒนาฟีเจอร์ใหม่ๆ
- **เพื่อการรักษาความปลอดภัย:** เพื่อป้องกัน ตรวจสอบ และระงับเหตุการณ์ที่อาจก่อให้เกิดความเสี่ยง
- **เพื่อการติดต่อสื่อสาร:** เพื่อแจ้งข้อมูลข่าวสารที่สำคัญเกี่ยวกับการอัปเดตระบบ

## 4. การใช้และการเปิดเผยข้อมูลส่วนบุคคล

เราจะไม่นำข้อมูลส่วนบุคคลของคุณไปขาย แลกเปลี่ยน หรือเปิดเผยให้แก่บุคคลภายนอก เว้นแต่ในกรณีดังต่อไปนี้:

- **ผู้ให้บริการภายนอก (Third-party Service Providers):** เราอาจใช้บริการของบุคคลที่สาม (เช่น ผู้ให้บริการเซิร์ฟเวอร์ หรือระบบฐานข้อมูล) เพื่อรองรับการทำงานของแอปพลิเคชัน โดยผู้ให้บริการเหล่านี้จะเข้าถึงข้อมูลได้เฉพาะเท่าที่จำเป็นและต้องอยู่ภายใต้มาตรการรักษาความลับ
- **แพลตฟอร์มที่คุณเชื่อมต่อ:** ระบบอาจส่งข้อมูลคำสั่งไปยัง API ของแพลตฟอร์มต่างๆ (เช่น Twitch, YouTube, Discord) เพื่อให้ฟีเจอร์ทำงานตามที่คุณอนุญาต
- **เมื่อกฎหมายบังคับ:** เราอาจเปิดเผยข้อมูลหากมีความจำเป็นเพื่อให้เป็นไปตามกฎหมาย หรือตามคำสั่งของหน่วยงานรัฐที่มีอำนาจหน้าที่

## 5. การโอนข้อมูลระหว่างประเทศ (International Data Transfer)

แอปพลิเคชัน TRAILBLAZER ใช้บริการโครงสร้างพื้นฐานที่ตั้งอยู่ทั้งในประเทศไทยและต่างประเทศ โดยเฉพาะ**สหรัฐอเมริกา** (เช่น Cloudflare และผู้ให้บริการ Cloud อื่นๆ) ซึ่งอาจทำให้ข้อมูลส่วนบุคคลของคุณถูกโอนหรือประมวลผลนอกราชอาณาจักร

เราดำเนินการดังต่อไปนี้เพื่อให้การโอนข้อมูลดังกล่าวเป็นไปอย่างปลอดภัย:

- ใช้ผู้ให้บริการที่มีมาตรฐานความปลอดภัยของข้อมูลในระดับสากล
- ข้อมูลจะถูกเข้ารหัสระหว่างการส่งผ่าน (Encryption in Transit) ด้วย HTTPS/TLS เสมอ
- เลือกผู้ให้บริการที่ผ่านการรับรองมาตรฐาน เช่น ISO 27001 หรือ SOC 2

## 6. นโยบายคุกกี้ (Cookie Policy)

เราใช้คุกกี้เพื่อการทำงานของแอปพลิเคชัน โดยแบ่งเป็นประเภทดังนี้:

| ประเภทคุกกี้ | วัตถุประสงค์ | จำเป็น? |
|---|---|---|
| **คุกกี้จำเป็น (Strictly Necessary)** | จัดการ Session การเข้าสู่ระบบ และรักษาสถานะการใช้งาน | ✅ จำเป็น ปิดไม่ได้ |
| **คุกกี้การทำงาน (Functional)** | จดจำการตั้งค่าและ Preferences ของคุณ | ⚙️ ปิดได้ แต่อาจกระทบการใช้งาน |

**คุกกี้จำเป็น** ถูกใช้เพื่อให้แอปพลิเคชันทำงานได้เท่านั้น เราไม่ใช้คุกกี้เพื่อการโฆษณาหรือติดตามพฤติกรรมการท่องเว็บของคุณ

## 7. ระยะเวลาการเก็บรักษาข้อมูล (Data Retention)

| ประเภทข้อมูล | ระยะเวลาเก็บรักษา |
|---|---|
| ข้อมูลบัญชีและการตั้งค่า | ตลอดระยะเวลาที่บัญชีของคุณยังเปิดใช้งาน |
| Access Tokens / Refresh Tokens | จนกว่าจะถูก Revoke หรือหมดอายุตามที่แพลตฟอร์มกำหนด |
| ข้อมูล Session และ Cookies | จนกว่า Session จะสิ้นสุดหรือคุกกี้หมดอายุ |
| **ข้อมูลทั้งหมดหลังปิดบัญชี** | **ลบทันทีเมื่อคุณลบบัญชีผู้ใช้งาน** |

> เราจะดำเนินการลบข้อมูลของคุณออกจากระบบและ Backup ทั้งหมดภายในระยะเวลาอันสมควรหลังจากได้รับคำขอ

## 8. มาตรการรักษาความปลอดภัยของข้อมูล

เรามีมาตรการทางเทคนิคและการบริหารจัดการที่เหมาะสมเพื่อปกป้องข้อมูลส่วนบุคคลของคุณ ซึ่งรวมถึง:

- การเข้ารหัสข้อมูล (Encryption) ในการส่งผ่านข้อมูลทางอินเทอร์เน็ต (HTTPS/TLS)
- การจัดเก็บโทเค็นและข้อมูลสำคัญในฐานข้อมูลที่มีระบบรักษาความปลอดภัย
- การจำกัดสิทธิ์การเข้าถึงข้อมูลเฉพาะเท่าที่จำเป็น

## 9. สิทธิของเจ้าของข้อมูลส่วนบุคคล

ภายใต้กฎหมาย PDPA คุณมีสิทธิในข้อมูลส่วนบุคคลของคุณ ดังนี้:

| สิทธิ | คำอธิบาย |
|---|---|
| **สิทธิในการเข้าถึง** (Right of Access) | ขอรับสำเนาข้อมูลส่วนบุคคลของคุณที่เราเก็บรักษาไว้ |
| **สิทธิในการแก้ไขข้อมูล** (Right to Rectification) | ขอให้เราแก้ไขข้อมูลที่ไม่ถูกต้องหรือทำให้เป็นปัจจุบัน |
| **สิทธิในการลบข้อมูล** (Right to Erasure) | ขอให้เราลบหรือทำให้ข้อมูลไม่สามารถระบุตัวตนได้ |
| **สิทธิในการระงับการใช้ข้อมูล** (Right to Restriction) | ขอให้เราระงับการใช้ข้อมูลของคุณชั่วคราว |
| **สิทธิในการโอนย้ายข้อมูล** (Right to Data Portability) | ขอรับข้อมูลของคุณในรูปแบบที่สามารถนำไปใช้กับบริการอื่นได้ |
| **สิทธิในการคัดค้าน** (Right to Object) | คัดค้านการประมวลผลข้อมูลที่อาศัยฐาน Legitimate Interest |
| **สิทธิในการถอนความยินยอม** (Right to Withdraw Consent) | ยกเลิกการให้สิทธิ์เชื่อมต่อบัญชีภายนอกได้ตลอดเวลา |

ในการใช้สิทธิเหล่านี้ กรุณาติดต่อเราผ่านช่องทางในข้อ 10 เราจะดำเนินการตอบสนองภายใน **30 วัน** นับจากวันที่ได้รับคำขอ

YouTube logo as an inline SVG (`currentColor`). Accepts any `<svg>` props - size it with `className="size-5"`; colour via `text-*` (utilities `text-discord` and `spotify` exist for brand colours).

## Usage

```tsx
import { YouTube, Button } from "trailblazer-ui";

<Button variant="outline"><YouTube className="size-4" /> YouTube</Button>
```

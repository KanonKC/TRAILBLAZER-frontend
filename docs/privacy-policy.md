# นโยบายความเป็นส่วนตัว (Privacy Policy)

แอปพลิเคชัน **TRAILBLAZER** ("เรา") ให้ความสำคัญและเคารพต่อความเป็นส่วนตัวของผู้ใช้งาน ("คุณ") นโยบายความเป็นส่วนตัวฉบับนี้จัดทำขึ้นเพื่อให้สอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) เพื่ออธิบายให้คุณทราบถึงวิธีการที่เราเก็บรวบรวม ใช้ เปิดเผย และรักษาข้อมูลส่วนบุคคลของคุณ รวมถึงสิทธิต่างๆ ที่คุณมีในฐานะเจ้าของข้อมูล

## 1. ข้อมูลส่วนบุคคลที่เราเก็บรวบรวม
เราเก็บรวบรวมข้อมูลส่วนบุคคลของคุณเท่าที่จำเป็นต่อการให้บริการ โดยแบ่งออกเป็นประเภทต่างๆ ดังนี้:

*   **ข้อมูลบัญชีผู้ใช้หลัก (Twitch):** รหัสผู้ใช้ (Twitch ID), ชื่อผู้ใช้งาน (Username), ชื่อที่แสดง (Display Name), และรูปภาพโปรไฟล์ (Avatar URL)
*   **ข้อมูลบัญชีที่เชื่อมต่อ (Linked Accounts):** หากคุณเชื่อมต่อบัญชีอื่นๆ เช่น YouTube หรือ Discord เราจะเก็บรหัสผู้ใช้แพลตฟอร์ม (Platform User ID), ชื่อผู้ใช้ (Platform Username), และรูปภาพโปรไฟล์ (Platform Avatar URL)
*   **ข้อมูลการให้สิทธิ์เข้าถึง (Authentication Data):** โทเค็นสำหรับการเข้าถึง (Access Tokens) และโทเค็นสำหรับต่ออายุการเข้าถึง (Refresh Tokens) สำหรับ Twitch และบัญชีที่คุณเชื่อมต่อ เพื่อใช้ในการทำงานของระบบ
*   **ข้อมูลการใช้งานแอปพลิเคชันและการตั้งค่า:** 
    *   ข้อมูลการตั้งค่าวิดเจ็ตต่างๆ (เช่น First Word, Clip Shoutout, Drop Image, Export Video, Random DBD Perk)
    *   ข้อมูลไฟล์มีเดียที่คุณอัปโหลด (เช่น รูปภาพ, ไฟล์เสียง) เพื่อใช้งานร่วมกับวิดเจ็ต
    *   ข้อมูล Workflow และ Trigger ที่คุณปรับแต่งในระบบ
*   **ข้อมูลที่เก็บรวบรวมอัตโนมัติ:** ข้อมูลทางเทคนิค เช่น หมายเลข IP Address, ชนิดของเบราว์เซอร์, และข้อมูลคุกกี้ (Cookies) เพื่อใช้ในการจัดการเซสชัน (Session) การเข้าสู่ระบบ

## 2. วัตถุประสงค์ในการเก็บรวบรวมและการใช้ข้อมูล
เรานำข้อมูลส่วนบุคคลของคุณไปใช้เพื่อวัตถุประสงค์ดังต่อไปนี้:
*   **เพื่อให้บริการและจัดการบัญชี:** เพื่อยืนยันตัวตน เข้าสู่ระบบ และอำนวยความสะดวกในการใช้งานแอปพลิเคชัน TRAILBLAZER
*   **เพื่อการทำงานของระบบและวิดเจ็ต:** เพื่อให้วิดเจ็ต ฟีเจอร์ และบอทต่างๆ ทำงานร่วมกับช่อง Twitch ของคุณและแพลตฟอร์มอื่นๆ ได้อย่างถูกต้องตามที่คุณได้ตั้งค่าไว้
*   **เพื่อการปรับปรุงแอปพลิเคชัน:** เพื่อนำข้อมูลไปวิเคราะห์และพัฒนาฟีเจอร์ใหม่ๆ ให้ตอบสนองต่อความต้องการของผู้ใช้งานได้ดียิ่งขึ้น
*   **เพื่อการรักษาความปลอดภัย:** เพื่อป้องกัน ตรวจสอบ และระงับเหตุการณ์ที่อาจก่อให้เกิดความเสี่ยงต่อความปลอดภัยของระบบและผู้ใช้งาน
*   **เพื่อการติดต่อสื่อสาร:** เพื่อแจ้งข้อมูลข่าวสารที่สำคัญเกี่ยวกับการอัปเดตระบบ หรือให้ความช่วยเหลือเกี่ยวกับการใช้งาน

## 3. การใช้และการเปิดเผยข้อมูลส่วนบุคคล
เราจะไม่นำข้อมูลส่วนบุคคลของคุณไปขาย แลกเปลี่ยน หรือเปิดเผยให้แก่บุคคลภายนอก เว้นแต่ในกรณีดังต่อไปนี้:
*   **ผู้ให้บริการภายนอก (Third-party Service Providers):** เราอาจใช้บริการของบุคคลที่สาม (เช่น ผู้ให้บริการเซิร์ฟเวอร์ หรือระบบฐานข้อมูล) เพื่อรองรับการทำงานของแอปพลิเคชัน โดยผู้ให้บริการเหล่านี้จะเข้าถึงข้อมูลได้เฉพาะเท่าที่จำเป็นและต้องอยู่ภายใต้มาตรการรักษาความลับ
*   **แพลตฟอร์มที่คุณเชื่อมต่อ:** ระบบอาจส่งข้อมูลคำสั่งไปยัง API ของแพลตฟอร์มต่างๆ (เช่น Twitch, YouTube, Discord) เพื่อให้ฟีเจอร์ทำงานตามที่คุณอนุญาต
*   **เมื่อกฎหมายบังคับ:** เราอาจเปิดเผยข้อมูลหากมีความจำเป็นเพื่อให้เป็นไปตามกฎหมาย หรือตามคำสั่งของหน่วยงานรัฐที่มีอำนาจหน้าที่

## 4. มาตรการรักษาความปลอดภัยของข้อมูล
เรามีมาตรการทางเทคนิคและการบริหารจัดการที่เหมาะสมเพื่อปกป้องข้อมูลส่วนบุคคลของคุณจากการสูญหาย การเข้าถึง การใช้ การเปลี่ยนแปลง หรือการเปิดเผยโดยมิชอบ ซึ่งรวมถึง:
*   การเข้ารหัสข้อมูล (Encryption) ในการส่งผ่านข้อมูลเครือข่ายอินเทอร์เน็ต (HTTPS)
*   การจัดเก็บโทเค็นและข้อมูลสำคัญในฐานข้อมูลที่มีระบบรักษาความปลอดภัย
*   การจำกัดสิทธิ์การเข้าถึงข้อมูลส่วนบุคคลเฉพาะบุคลากรที่จำเป็นต้องเข้าถึงเพื่อปฏิบัติหน้าที่เท่านั้น

## 5. สิทธิของเจ้าของข้อมูลส่วนบุคคล
ภายใต้กฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA) คุณมีสิทธิในข้อมูลส่วนบุคคลของคุณ ดังนี้:
*   **สิทธิในการเข้าถึง (Right of Access):** ขอรับสำเนาข้อมูลส่วนบุคคลของคุณที่เราเก็บรักษาไว้
*   **สิทธิในการแก้ไขข้อมูล (Right to Rectification):** ขอให้เราแก้ไขข้อมูลที่ไม่ถูกต้อง หรือทำให้เป็นปัจจุบัน
*   **สิทธิในการลบข้อมูล (Right to Erasure):** ขอให้เราลบ ทำลาย หรือทำให้ข้อมูลส่วนบุคคลของคุณไม่สามารถระบุตัวตนได้ (เช่น การลบบัญชีผู้ใช้งาน)
*   **สิทธิในการระงับการใช้ข้อมูล (Right to Restriction of Processing):** ขอให้เราระงับการใช้ข้อมูลของคุณชั่วคราว
*   **สิทธิในการถอนความยินยอม (Right to Withdraw Consent):** คุณสามารถยกเลิกการให้สิทธิ์การเชื่อมต่อบัญชี (Revoke Access) กับแพลตฟอร์มภายนอกได้ตลอดเวลา โดยการจัดการสิทธิ์ในแอปพลิเคชันหรือในบัญชีของแพลตฟอร์มนั้นๆ
